## 🌟 Advanced Futuristic Features

This portfolio is packed with interactive visual features engineered to demonstrate technical mastery in front-end interaction design and web performance:

### 🧠 1. Neural Network Background
*   **What it is:** A high-fidelity, native HTML5 Canvas particle system.
*   **Interaction:** Floating nodes move gracefully across the screen, dynamically casting connecting webs (links) as they pass near each other.
*   **Responsiveness:** The entire network actively reacts to your mouse coordinate movement, shifting and repelling particles to create a living "digital brain" environment.

### 💳 2. Interactive Project Showcase Cards
*   **What it is:** A sophisticated 3D tilt effect integrated into your projects' showcase layout.
*   **Interaction:** Project cards dynamically lean and tilt towards your cursor as you hover over them, giving the cards simulated physical depth.
*   **Aesthetics:** Complemented by a glassmorphic background blur and a subtle internal glow effect that changes position relative to the cursor coordinate.

### 🛡️ 3. Cybersecurity Scanning Lines
*   **What it is:** Periodic, rhythmic vertical scanning animations running across technical components and data sheets.
*   **Design Rationale:** Designed to evoke a system diagnostics HUD, reinforcing themes of structural integrity, system analysis, and advanced cybersecurity monitoring.

### ⚡ 4. Digital Glitch Effects
*   **What it is:** Raw, highly stylized mechanical glitch animations attached to primary headlines.
*   **Interaction:** Hovering over section numbers or titles triggers a sudden chromatic split transition, adding an energetic layer of raw technical power to an otherwise sleek, clean, and professional layout.

## 💻 Local Development Setup

To clone, run, and preview the personal portfolio locally on your machine, ensure you have [Node.js](https://nodejs.org/) installed:

### 1. Clone the Repository
```bash
git clone https://github.com/deedeestephen/portfolio.git
cd portfolio
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Once started, the application will render locally at:
👉 **`http://localhost:5173/`**

### 4. Build for Production
```bash
npm run build
```
This command compiles optimized assets into the `/dist` directory, fully minified and ready to serve.

## 🚀 How to Deploy

The portfolio is configured for effortless static deployment to any major host:

### Option A: GitHub Pages (Recommended)
This portfolio is highly optimized for deployment directly through GitHub Pages.
1. Go to your repository settings on GitHub.
2. In the left menu, select **Pages**.
3. Under **Build and deployment**, set Source to **GitHub Actions**.
4. In your project, you can set up a simple GitHub Actions workflow (e.g. `.github/workflows/deploy.yml`) to automatically build and deploy your Vite app whenever you push to `main`.

> [!TIP]
> Make sure your `vite.config.js` has the correct `base` property configured if you are hosting under a subpath (e.g. `base: '/portfolio/'`). If it's a custom domain, `base: '/'` is perfect.

### Option B: Vercel / Netlify / Cloudflare Pages
1. Sign in to your preferred hosting provider dashboard (e.g., [Vercel](https://vercel.com/)).
2. Import the cloned repository `deedeestephen/portfolio`.
3. Configure the following build settings:
    *   **Build Command:** `npm run build`
    *   **Output Directory:** `dist`
4. Click **Deploy**. Your portfolio will be live in seconds with automatic SSL and global CDN caching.
